## Lenguaje de programación
* **Java** (Implementado bajo un diseño modular).

## Pasos para compilar y ejecutar
1. Clonar o descargar el repositorio en tu equipo.
2. Abrir el proyecto en **IntelliJ IDEA**.
3. Asegurarse de que el entorno esté configurado correctamente con el JDK.
4. Ejecutar la clase principal **`Lanzador_gaus.java`**.

## Ejemplo de prueba y salida por consola
Al ejecutar el programa, se obtiene el siguiente resultado en consola:

Soluciones del sistema:
= 3.0
= -2.5
= 7.000000000000002

Proceso finalizado con éxito.
